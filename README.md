# 💼 Salary Prediction for Indian Job Market

A Machine Learning-based Salary Prediction System designed to estimate salaries in the Indian job market based on candidate attributes such as education, experience, job role, skills, location, and other relevant factors.

---

## 📖 Project Overview
This project analyzes historical salary data and predicts an expected salary range, helping **job seekers, recruiters, and organizations** make informed compensation decisions.

---

## 🎯 Objectives
- Predict salaries for professionals in the Indian job market.  
- Analyze the impact of experience, education, and skills on salary.  
- Build an end-to-end Machine Learning pipeline.  
- Deploy an interactive web application for real-time salary prediction.  

---

## 📊 Dataset
The dataset contains information related to:
- Education Level
- Education Degree
- Specialization  
- Years of Experience  
- Job Sector  
- Company Size    
- City Tier  
- Job Role  
- Salary (Target Variable)  

---

## 🧠 Model Performance
Evaluated using regression metrics:
- **R² Score**: `0.92` → Strong explanatory power of the model.  
- **Mean Squared Error (MSE)**: `109844523710.09` → Indicates variance between predicted and actual salaries.
